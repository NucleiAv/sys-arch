The slow feed

Users in other countries say the feed loads slowly and uses a lot of data.

Round 1. Find the problemsRound 2. Privacy and workarounds

Uploads go through the API servers. The feed sends the original 3 MB image to every phone. Images are served from one data center with no CDN.

Round 2. Privacy and workarounds

Pocket card. Keep this

  • Presigned URLs. Bytes go phone to storage.
  • Resize in the background. Several sizes and formats.
  • Metadata in a sharded database. Bytes in object storage.
  • CDN with versioned URLs. Strip GPS data.
