Review a startup's AWS diagram

A startup drew its AWS setup. Find the risky parts.

Round 1. Find the fixesRound 2. Pick a database

Orbitfit runs two EC2 servers in a public subnet in one zone. Their security group allows SSH from anywhere. The RDS PostgreSQL database is in the same public subnet with a public IP. User photos are in an S3 bucket with public read access.

Round 1. Find the fixes

Round 2. Pick a database

Pocket card. Keep this

  • Public subnets for load balancers only.
  • Chain security groups by reference.
  • Block Public Access on S3, use CloudFront.
  • RDS Multi-AZ for failover, replicas for reads.
  • DynamoDB keys come from queries.
