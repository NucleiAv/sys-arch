Infra18 pages

Infrastructure, from your first commit to the cloud

Git, GitHub, GitHub Actions, Linux, Docker, Kubernetes, AWS, Terraform and safe deploys. Each lesson ends with practice that includes real commands and config files. Each level ends with a practice page.

In plain words

System design tells you which boxes you need. Infra is how you build, ship and run those boxes for real. You do not need to know cloud or Linux before you start. Each lesson starts from zero.

Do the lessons in order. Each lesson ends with practice that includes commands and config files. Each level ends with a practice page. Try every command on your own computer if you can. Git and Docker are free to install.
