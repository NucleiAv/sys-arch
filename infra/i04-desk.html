Fix a broken workflow

A team's first GitHub Actions workflow does not work as they want. Read the YAML and fix it.

Round 1. Read the workflowRound 2. Write the fix

Pocketbook wants tests on every pull request and a deploy only from main after tests pass.

Round 1. Read the workflow

on:
  push:
    branches: [main]
jobs:
  test:
    runs-on: ubuntu-latest
    steps:
      - run: npm test
  deploy:
    runs-on: ubuntu-latest
    steps:
      - run: ./deploy.sh

Round 2. Write the fix

Pocket card. Keep this

  • CI on every pull request, fast.
  • needs for order, if for conditions.
  • Build once, promote the same image.
  • OIDC instead of long lived keys.
