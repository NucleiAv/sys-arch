Fix a team's compose.yaml

A blog app runs with Compose but has three problems. Read the file and fix them.

Round 1. Read the file

Inkwell runs a blog with a web service and a MySQL service in Compose.

Round 1. Read the file

services:
  web:
    build: .
    environment:
      DB_HOST: localhost
    depends_on: [mysql]
  mysql:
    image: mysql:8
    ports:
      - "3306:3306"
    environment:
      MYSQL_ROOT_PASSWORD: root

Pocket card. Keep this

  • One file, one command.
  • Service names are host names.
  • Named volumes for data.
  • Health checks for real readiness.
