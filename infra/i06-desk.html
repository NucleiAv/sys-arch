Shrink and secure an image

A team's image is huge, slow to build and not safe. Fix the Dockerfile.

Round 1. Read the DockerfileRound 2. Make it small

Quillpad builds a Python API. Every small code change takes 6 minutes to build, the image is 1.8 GB, and it runs as root.

Round 1. Read the Dockerfile

FROM python:3.12
COPY . /app
WORKDIR /app
RUN pip install -r requirements.txt
CMD ["python", "main.py"]

Round 2. Make it small

Pocket card. Keep this

  • Image is the template, container is the running copy.
  • Copy dependency files first for the cache.
  • Slim base, multi-stage, USER, .dockerignore.
  • Secrets at run time, version tags always.
