How to use this site

Go in order the first time. Each level uses words from the one before. Mark a page done at the top when you finish it, and your route on the home page fills in.

Write your own answer before you open any model answer. The feedback compares your words with the key points, so it only helps if you try first. Everything you write stays in your browser.

When you finish the concepts, do the designs out loud, with a timer, as if someone is listening. That is what a real interview feels like. Then use the interview page for random practice.
