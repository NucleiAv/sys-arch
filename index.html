How to use this site

Go in order the first time. Each level uses words from the one before. Mark a page done at the bottom when you finish it, and your route on the home page and your plan fill in.

Write your own answer before you open any model answer. The feedback compares your words with the key points, so it only helps if you try first. Everything you write stays in your browser.

Try every Git, Docker and Terraform command on your own computer. When you finish the concepts, do the designs out loud, with a timer, as if someone is listening. Then use the interview page for random practice.
