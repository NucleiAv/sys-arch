System design concepts, from zero to mastery

Thirty eight lessons in six levels. Each lesson explains one idea in plain words, shows it step by step and ends with practice. Each level ends with a practice page that mixes all its lessons.

Level 1. Foundations

Learn what system design is, how one request travels, and how programs talk with APIs. Then learn to estimate size and to grow from one server to many.

One product, a connected infant incubator, runs through every lesson.
